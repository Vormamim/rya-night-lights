# RYA Night Lights Flash Cards

Flash cards for learning COLREGs navigation lights for the RYA Day Skipper course. There are 26 light configurations covering power, sail, towing, NUC/RAM/CBD, fishing, pilot, anchored/aground and specialist vessels.

Play: https://vormamim.github.io/rya-night-lights/

This is a study aid only. Check the RYA Day Skipper handbook or the full COLREGs text before relying on anything here.
